## 📋 Step 1: Pre-Submission Checklist

- [ ] **GitHub Account Linked:** Make sure your GitHub account is linked at [points.genlayer.foundation/profile](https://points.genlayer.foundation/profile).
- [ ] **Builder Welcome Completed:** Verify you have completed the initial journey at `/builders/welcome`.
- [ ] **Public GitHub Repository:** Push this `genlayer-forex-oracle` folder to a public GitHub repository.

---

## 🚀 Step 2: Deploy Contract to Testnet / Studio

1. Open **[GenLayer Studio](https://studio.genlayer.com)**.
2. Create a contract file named `forex_sentiment_oracle.py` and paste `contracts/forex_sentiment_oracle.py`.
3. Click **Deploy**.
4. Run `update_sentiment("EURUSD")` to execute an on-chain AI sentiment analysis transaction.
5. Save the **Deployed Contract Address** and **Transaction Hash**.
